Assinatura espectral

Assinatura espectral

Para que serve: comparar a "impressão digital" da amostra com a água boa e a podre. Quanto mais alto o ponto, mais a água bloqueia aquela cor. Os picos indicam o que tem na água (as faixas no topo mostram o quê).

Aguardando amostrasGrave a água limpa (BOOT → 1) e meça uma amostra com nome (ex.: n lagoa_p1).

Indicadores

O que esta amostra indica

Para que serve: dizer, em palavras, o que tem nesta água e em que quantidade. Barra verde = pouco; amarela = moderado; vermelha = muito. Fotos: Wikimedia Commons (Algal bloom at Anderson Lake State Park, CC BY-SA 4.0; Lake Burley Griffin cyanobacteria, CC BY-SA 3.0; Some Tea With Your River, Sir?, CC BY 2.0; Muddy water, Belfast, CC BY-SA 2.0).

Comparação

Semelhança com as referências

Para que serve: responder "esta água se parece com o quê?". A barra maior é a água de referência mais parecida (boa, podre, chá, terra ou algas).

Sem referênciasO branco é a referência do cálculo e não é comparado. Referências: n agua_boa, BOOT → 2, n ref_cha, n ref_terra, n ref_algas.

Validação

Validação do sensor – série de diluição

Para que serve: provar que o aparelho mede certo. Colocamos um corante cada vez mais forte; se os pontos formam uma reta (R² perto de 1), o sensor responde do jeito que a ciência prevê.

Ainda não há série de diluiçãoMeça pelo menos 3 concentrações de cada corante: n dil_amarelo_25 → m, n dil_amarelo_50 → m, n dil_amarelo_100 → m.
